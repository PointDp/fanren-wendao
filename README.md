# 凡人问道·文字卷

纯文字修仙网页游戏。山村少年李恒，伪灵根，从杂役做起，一步一机缘、一步一代价，走过炼气、筑基、结丹、元婴，直至人界顶点——化神。而化神之上，人界再无进阶之路：寿元只减不增，想求仙路尽头，就得自己找法子飞升离界，否则老死于此。

凡人流笔法：谨慎的小人物、有代价的选择、延迟兑现的因果。你在大比中救过的人、顶过的罪、欠下的账，会在数章之后回到你身上——或报恩，或索命。

## 在线游玩

**[▶ 点这里直接开玩](https://PointDp.github.io/fanren-wendao/)**（发布后此链接生效）

无需安装、无需注册。进度自动存入浏览器 localStorage，支持手动存档三槽位 + 自动存档 + 章节检查点。

## 特性

- **零依赖零构建**：纯 HTML/CSS/JS，双击 `index.html` 即可离线游玩
- **完整人界篇**：约 13 万字、190+ 剧情节点，三大结局（飞升离界 / 坐化传道 / 老死盖棺定论——结局文随你一生的因果而变）
- **无随机数**：所有成败由你的准备（道具、人脉、因果、灵石）决定，凡人靠算计不靠运气
- **寿元压迫**：时间即生命，闭关快进=燃烧寿元；化神之后，倒计时开始
- **加速与跳过**：看过的剧情自动加速，闭关可按天/月/年乃至百年快进
- **死亡不吞进度**：专属死法文案（兵解/丹毒/寿终/战死/中毒/冻毙六档），从章节检查点复活
- **开发者面板**：游戏中按 `~` 键（金手指：跳境界/跳章节/调属性/死亡豁免）

## 本地运行

无需构建：

```bash
git clone https://github.com/PointDp/fanren-wendao.git
```

然后双击 `index.html` 即可。

## 开发

```bash
node --test "tests/*.test.mjs"   # Node 22+，247 个测试
```

- 引擎：五种节点（scene / choice / hub / combat / death）+ 效果 DSL（res / item / karma / flag / time / death）
- 剧情内容与引擎完全分离，见 `js/content/ch1.js ~ ch7.js`
- 设计文档见 `docs/superpowers/specs/`，实现计划见 `docs/superpowers/plans/`
